## Prompt 1
Quiero crear un ejercicio de HTML, CSS y JavaScript partiendo de una plantilla simple con index.html y script.js. Necesito una aplicación que incluya dos modos:
1. Un cronómetro con botones Start, Pause y Reset.
2. Una cuenta atrás configurable por minutos y segundos, también con Start, Pause y Reset.

Requisitos:
- Diseño visual limpio y moderno, inspirado en una web de cronómetro online.
- El cronómetro debe mostrar horas, minutos y segundos.
- La cuenta atrás debe permitir introducir minutos y segundos.
- Al finalizar la cuenta atrás debe aparecer un mensaje indicando que el tiempo ha terminado.
- Código separado en HTML, CSS y JavaScript.
- Código sencillo, claro y fácil de explicar en clase.

---

## Prompt 2
Mejora el diseño para que se parezca más a un cronómetro online:
- pantalla grande tipo display digital
- botones visibles y redondeados
- selector para cambiar entre cronómetro y cuenta atrás
- responsive para móvil
- colores limpios y legibles

---

## Prompt 3
Revisa el código JavaScript para evitar errores comunes:
- que no se creen múltiples intervalos al pulsar Start varias veces
- que Reset deje el cronómetro a cero
- que la cuenta atrás se pueda pausar y reiniciar correctamente
- que al llegar a cero se detenga automáticamente

---

## Prompt final
Crea una solución completa de una app web con HTML, CSS y JavaScript que incluya:
- un cronómetro
- una cuenta atrás configurable
- botones Start, Pause y Reset en ambos modos
- selector de modo
- diseño visual moderno inspirado en un online stopwatch
- código claro, comentado y fácil de entender
- formato final listo para entregar en un ejercicio académico
